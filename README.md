# Meow! 日本語達陣 (Meow! Japanese Touchdown)

一個專為日檢 (JLPT) 考生設計的互動式自學門戶網站，系統化收錄 N1 至 N5 的核心文法與單字。

## 🎯 項目目標

本項目的目標是提供一個視覺精美、功能完整的互動式平台，幫助學習者：
- **系統化學習**：從 N5 入門到 N1 高級，涵蓋完整的 JLPT 文法體系。
- **高效背誦**：透過「雙向智能學習卡」，從「日譯中」與「中譯日」兩個維度深度掌握單字。
- **進度追蹤**：內置本地存儲 (LocalStorage) 功能，自動記錄已掌握的文法與單字，實時顯示學習進度。
- **實戰導向**：所有單字與文法均配有日語例句與中文翻譯。

## 🚀 主要功能

- **核心文法系統**：每個級別收錄數十至上百項精選文法，配有詳細描述與實戰例句。
- **單字庫**：系統化整理各級別單字，包含漢字、假名、中文意義及例句。
- **雙向智能學習卡**：
  - **日譯中模式**：訓練對單字的反應速度與中文理解。
  - **中譯日模式**：挑戰從意思回推正確的日文拼寫與發音。
- **智能進度管理**：
  - **掌握勾選**：手動標記已學會的內容。
  - **隱藏已掌握**：一鍵過濾，專注於尚未攻克的難點。
  - **進度可視化**：動態進度條實時反饋學習達成率。
- **雲端進度同步**：整合 Google Drive API，支持跨裝置同步學習進度、單字卡分數及顯示偏好。具備自動背景同步與「最新更動優先」的衝突解決機制。
- **全平台適應**：採用 Tailwind CSS 構建，支持桌機與行動裝置瀏覽。

## ☁️ 雲端同步技術細節

本網站具備完善的跨裝置資料同步機制，技術重點如下：

- **安全儲存**：使用 Google OAuth 2.0 進行驗證，資料儲存於使用者 Google Drive 的 `appDataFolder`（應用程式專用資料夾）。該資料夾對使用者隱藏，確保同步檔案不會被意外刪除或更改。
- **同步觸發時機**：
  - **初次載入**：進入任何 N1-N5 學習頁面時，系統會自動檢查雲端版本。若雲端資料較新，將自動下載並更新本地介面。
  - **自動背景同步**：當您勾選文法、單字或在單字卡得分時，系統會自動觸發背景同步。
- **智慧延時機制 (Debounce)**：為了優化效能並減少 Google Drive API 的呼叫次數，自動同步具備 **3 秒防抖延遲**。當您連續操作時，系統會等待您停止動作滿 3 秒後，才執行一次性的雲端寫入。
- **衝突解決 (Conflict Resolution)**：採用 **「最新更動優先 (Last-Write-Wins)」** 策略。系統會在本地紀錄每次變動的時間戳記，同步時比對「本地」與「雲端」的最後修改時間，確保跨裝置間的進度完全同步，即使是「取消勾選 (Uncheck)」的操作也能被正確反映。
- **同步內容**：涵蓋所有級別的文法掌握名單、單字雙向得分紀錄、以及「是否隱藏已掌握」的顯示偏好。
