# Meow! 日本語達陣 (Meow! Japanese Touchdown)

一個專為日檢 (JLPT) 考生設計的互動式自學門戶網站，系統化收錄 N1 至 N5 的核心文法與全量單字。

## 🎯 項目目標

本項目的目標是提供一個視覺精美、功能完整的互動式平台，幫助學習者：
- **系統化學習**：從 N5 入門到 N1 高級，涵蓋完整的 JLPT 文法體系。
- **高效背誦**：透過「雙向智能學習卡」，從「日譯中」與「中譯日」兩個維度深度掌握單字。
- **進度追蹤**：內置本地存儲 (LocalStorage) 功能，自動記錄已掌握的文法與單字，實時顯示學習進度。
- **實戰導向**：所有單字與文法均配有日語例句與中文翻譯。

## 🚀 主要功能

- **核心文法系統**：每個級別收錄數十至上百項精選文法，配有詳細描述與實戰例句。
- **全量去重單字庫**：系統化整理各級別單字，包含漢字、假名、中文意義及例句。
- **雙向智能學習卡**：
  - **日譯中模式**：訓練對單字的反應速度與中文理解。
  - **中譯日模式**：挑戰從意思回推正確的日文拼寫與發音。
- **智能進度管理**：
  - **掌握勾選**：手動標記已學會的內容。
  - **隱藏已掌握**：一鍵過濾，專注於尚未攻克的難點。
  - **進度可視化**：動態進度條實時反饋學習達成率。
- **全平台適應**：採用 Tailwind CSS 構建，支持桌機與行動裝置瀏覽。

## 📂 文件結構

- `index.html`: 自學門戶首頁，導向各級別學習頁。
- `jp_n5.html` ~ `jp_n1.html`: 各級別專屬的互動學習頁面。

## 🛠️ 維護與特點

本項目致力於提供精確且完整的日檢資源，所有學習頁面均經過精心校對與排版，確保學習者獲得最高質量的日語學習體驗。
